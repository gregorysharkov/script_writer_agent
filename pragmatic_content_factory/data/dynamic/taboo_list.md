# Taboo List

Prohibited phrases, clichés, and hype terms that should never appear in content.

## Hype Terms (Avoid Completely)

- "revolutionary"
- "game-changing"
- "cutting-edge"
- "next-generation"
- "disruptive"
- "paradigm shift"
- "synergy"
- "leverage" (as a verb)
- "10x" (without concrete data)
- "magic"
- "seamlessly"
- "master the basics"

## Overused Clichés

- "Let's dive in"
- "Without further ado"
- "At the end of the day"
- "Low-hanging fruit"
- "Move the needle"
- "Circle back"
- "churn"

## Emotional Language (Replace with Concrete)

- "Amazing" → Use specific outcomes
- "Incredible" → Use metrics
- "Awesome" → Describe what makes it useful
- "Excited" → Show through action/results

## Emoji Rules

### Allowed (Functional)
- ⬇️ (pointing to content)
- → (flow/progression)
- ✅ (checkmark for lists)
- ❌ (indicating problems)
- 📊 (data/metrics context)

### Prohibited (Emotional)
- 🔥 (fire)
- 🚀 (rocket)
- 💯 (hundred points)
- 🎉 (celebration)
- 😍 (heart eyes)
- 🤯 (mind blown)
